# HH AutoMode

Программа сама ищет вакансии на hh.ru по ключевым словам и массово отправляет на них отклики с сопроводительным письмом. Всё управляется из одного окна.

---

## 1. Что нужно установить (для ламеров)

### Python
1. Скачай Python 3.10 или новее: https://www.python.org/downloads/
2. В установщике **обязательно поставь галочку «Add python.exe to PATH»**, затем «Install Now».
3. Проверка — в командной строке (Win+R → `cmd`):
   ```
   python --version
   ```

### Google Chrome
Программа работает через браузер Chrome — он должен быть установлен. Драйвер для Chrome скачается автоматически при первом запуске.


Установка одной командой (из папки, где лежат `main.py` и `requirements.txt`):
```
pip install -r requirements.txt
```
или без файла:
```
pip install requests selenium webdriver-manager
```

---

## 2. Запуск (Windows)

Win + R -> cmd -> Enter

```
cd C:\путь\к\папке
python main.py
```

При первом запуске рядом с `main.py` появятся служебные файлы:

| Файл / папка | Что хранит |
|---|---|
| `chrome_profile/` | профиль браузера с твоим входом на hh.ru |
| `keywords.txt` | ключевые слова для поиска |
| `cover_letter.txt` | сопроводительное письмо |
| `vacancies_links.txt` | все найденные вакансии |
| `applied_links.txt` | вакансии, которые уже обработаны |

Не удаляй их — программа по ним помнит, куда уже откликалась, и не откликается повторно.

## 3. Как пользоваться — по шагам

### Шаг 1. Авторизация (один раз)
1. Нажми **🔑 Авторизоваться** — откроется Chrome.
2. Войди в свой аккаунт hh.ru вручную (телефон/почта, код).
3. Программа каждые 3 секунды проверяет вход. Как только увидит, что ты вошёл, — покажет «Авторизован ✅» и закроет браузер. На вход даётся **около 3 минут**.

Вход сохраняется в папке `chrome_profile`, повторять его при каждом запуске не нужно.
**🗑️ Сбросить авторизацию** удаляет этот профиль — например, чтобы войти в другой аккаунт.

### Шаг 2. Ключевые слова и регион
- Впиши слово в поле и нажми **Добавить** (или Enter). Чтобы удалить — выдели в списке и нажми **Удалить**.
- Поиск идёт **только по названию вакансии** (например `Python`, `QA`, `AQA`).
- **Регион поиска**:
  - «Кроме РФ и РБ» — все страны, кроме России и Беларуси;
  - «Только РФ и РБ» — только Россия и Беларусь;
  - «Все страны».

### Шаг 3. Поиск вакансий
Нажми **🚀 Запустить поиск вакансий**. Откроется браузер и пройдёт по каждому слову и каждой стране (до 40 страниц по 50 вакансий). Новые ссылки сохраняются в `vacancies_links.txt` после каждого ключевого слова.

⏱ Со многими странами поиск идёт долго — от десятков минут до нескольких часов. Прогресс видно в «Журнале событий».

### Шаг 4. Сопроводительное письмо
Отредактируй текст в поле «Сопроводительное письмо». Он сохранится автоматически при запуске откликов.

### Шаг 5. Автоотклики
Нажми **💼 Запустить автоотклики**. Программа по очереди открывает найденные вакансии, жмёт «Откликнуться», вставляет письмо и отправляет.

- За один запуск — не больше **200 откликов**.
- Между откликами пауза **30 секунд** (200 откликов ≈ 2 часа).
- Если лимит достигнут, просто запусти ещё раз позже — продолжит с того места, где остановился.

Блок **Статистика** показывает: сколько собрано, сколько обработано и сколько осталось.

## 4. Важно знать

- **Пока идёт поиск или отклики — не закрывай окно браузера** и не открывай Chrome с тем же профилем вручную.
- **«Обработано» ≠ «откликнулся».** Вакансия тоже помечается обработанной, если:
  - на ней нет кнопки «Откликнуться» (например, отклик только на сайте компании);
  - вместо поля для письма открылась анкета или тест — такие отклики фактически **не отправляются**.
  Их можно найти вручную по списку в `applied_links.txt`.
- **Риск для аккаунта.** hh.ru не приветствует автоматизацию. Слишком частые или массовые отклики могут привести к капче или ограничениям аккаунта. Паузы и лимит в программе — разумный минимум, уменьшать их не стоит.
- Если hh.ru поменяет вёрстку сайта, кнопки перестанут находиться — в журнале появятся сообщения «не найдена».

Настройки (лимиты, паузы, число страниц) меняются в начале `main.py`, в блоке **КОНФИГУРАЦИЯ**.

## 5. Частые ошибки (для ламеров)

| Ошибка | Что делать |
|---|---|
| `'python' не является внутренней командой` | Python установлен без галочки «Add to PATH» — переустанови с ней |
| `No module named 'selenium'` | не установлены библиотеки — `pip install -r requirements.txt` |
| `user data directory is already in use` | закрой все окна Chrome, открытые программой, и повтори |
| «Требуется авторизация» | пройди Шаг 1 заново |
| Ошибка удаления профиля при сбросе | закрой браузер и нажми сброс ещё раз |
