## Введение

AI Telegram Помощник - это интеллектуальный бот, который понимает естественные команды и помогает в поиске работы прямо из телефона.

**Что он умеет:**
- 💬 Понимает обычный человеческий язык
- 🔍 Ищет подходящие вакансии
- 📄 Показывает и анализирует резюме
- 📊 Дает статистику с умными выводами
- 💡 Предлагает персональные рекомендации
- 🚀 Автоматически откликается на вакансии
- 🤝 Ведет диалог с контекстом

## Установка и настройка

### 1. Создание бота

1. Открой [@BotFather](https://t.me/BotFather) в Telegram
2. Отправь `/newbot`
3. Введи название бота (например: `My HH Assistant`)
4. Введи username (например: `my_hh_assistant_bot`)
5. Скопируй токен (выглядит как `123456:ABC-DEF...`)

### 2. Узнай свой Telegram ID

1. Открой [@userinfobot](https://t.me/userinfobot)
2. Нажми Start
3. Скопируй свой ID (число, например `987654321`)

### 3. Установи зависимости

```bash
pip install python-telegram-bot
```

### 4. Настрой переменные окружения

**Linux/macOS:**
```bash
export TELEGRAM_BOT_TOKEN="123456:ABC-DEF..."
export TELEGRAM_OWNER_ID="987654321"

# AI (выбери один вариант)

# Вариант A: OpenAI
export OPENAI_API_KEY="sk-..."
export OPENAI_MODEL="gpt-3.5-turbo"

# Вариант B: Ollama (локальный)
export OLLAMA_HOST="http://localhost:11434"
export OLLAMA_MODEL="llama2"
```

**Windows:**
```cmd
set TELEGRAM_BOT_TOKEN=123456:ABC-DEF...
set TELEGRAM_OWNER_ID=987654321

REM AI
set OPENAI_API_KEY=sk-...
set OPENAI_MODEL=gpt-3.5-turbo
```

### 5. Запуск

**Первый запуск (с авторизацией):**
```bash
# Сначала запусти обычный режим для авторизации на HH.ru
python main.py

# После авторизации можно запускать AI бота
python main.py --telegram-ai
```

**Последующие запуски:**
```bash
python main.py --telegram-ai
```

Бот будет работать в фоновом режиме. Браузер останется открытым для выполнения операций.

## AI Провайдеры

### OpenAI (платный)

**Преимущества:**
- Высокое качество понимания
- Быстрая обработка
- Поддержка GPT-3.5 и GPT-4

**Настройка:**
```bash
export OPENAI_API_KEY=sk-...
export OPENAI_MODEL=gpt-3.5-turbo  # или gpt-4
```

**Стоимость:**
- GPT-3.5-turbo: ~$0.002 / 1000 токенов
- GPT-4: ~$0.03 / 1000 токенов
- В среднем: $1-5 / месяц при активном использовании

### Ollama (локальный, бесплатный)

**Преимущества:**
- Полностью бесплатный
- Работает оффлайн
- Конфиденциальность (данные не уходят в интернет)

**Установка:**
```bash
# Linux/macOS
curl -fsSL https://ollama.com/install.sh | sh

# Windows - скачайте с https://ollama.com/download
```

**Запуск:**
```bash
# Скачать модель
ollama pull llama2

# Запустить сервер (в отдельном терминале)
ollama serve
```

**Настройка:**
```bash
export OLLAMA_HOST=http://localhost:11434
export OLLAMA_MODEL=llama2
```

**Рекомендуемые модели:**
- `llama2` - универсальная, хорошо пишет по-русски
- `mistral` - быстрая и качественная
- `gemma` - легковесная от Google

**Системные требования:**
- 8GB RAM (минимум)
- 16GB RAM (рекомендуется для llama2)
- 4-8GB свободного места

## Troubleshooting

### Бот не отвечает

**Проверь:**
1. Токен правильный: `echo $TELEGRAM_BOT_TOKEN`
2. Owner ID правильный: `echo $TELEGRAM_OWNER_ID`
3. Бот запущен: `ps aux | grep telegram`

**Решение:**
```bash
# Перезапусти бота
pkill -f telegram_ai
python main.py --telegram-ai
```

### AI не работает

**OpenAI:**
```bash
# Проверь API ключ
curl https://api.openai.com/v1/models \
  -H "Authorization: Bearer $OPENAI_API_KEY"
```

**Ollama:**
```bash
# Проверь что сервер запущен
curl http://localhost:11434/api/tags

# Если нет - запусти
ollama serve
```

### Браузер закрывается

Не используй `--telegram-ai` с другими флагами:
```bash
# НЕ ДЕЛАЙ ТАК:
python main.py --telegram-ai --boost

# ДЕЛАЙ ТАК:
python main.py --telegram-ai
# Потом используй команды бота
```

### Медленная работа

**Если Ollama медленный:**
- Используй меньшую модель: `gemma` вместо `llama2`
- Добавь RAM
- Используй GPU (если есть)

**Если OpenAI медленный:**
- Проблема с интернетом
- Используй `gpt-3.5-turbo` вместо `gpt-4`

## Безопасность

### Важно!

1. **Храни токен в секрете** - не коммить в git
2. **Проверь Owner ID** - только ты должен управлять ботом
3. **Не публикуй токен** - каждый создает СВОЕГО бота
4. **Используй .env** - не храни секреты в коде

### Проверка безопасности

```bash
# Проверь что .env в .gitignore
cat .gitignore | grep .env

# Проверь что токен не в истории git
git log --all -p | grep TELEGRAM_BOT_TOKEN
```

## FAQ

**Q: Бот понимает русский и английский?**
A: Да, бот понимает оба языка.

**Q: Можно ли использовать без AI?**
A: Да, используй обычный бот: `python main.py --telegram`

**Q: Сколько стоит OpenAI?**
A: $1-5/месяц при активном использовании.

**Q: Ollama бесплатный?**
A: Да, полностью бесплатный.

**Q: Можно ли использовать на телефоне?**
A: Да! Бот работает в Telegram на любом устройстве. Сервер должен быть запущен на компьютере.

**Q: Бот работает 24/7?**
A: Да, если запущен на сервере или постоянно включенном компьютере.

**Q: Можно ли делиться ботом с друзьями?**
A: Нет, каждый создает СВОЕГО бота со своим токеном. Это безопаснее.

**Q: Бот хранит мои данные?**
A: Данные хранятся только локально в `browser_data/`. Никуда не отправляются (кроме AI провайдера если используешь OpenAI).
